# Source registry

The machine-readable [registry](sources.json) records monitored URLs, status, adapter, history, cadence, geographic scope and license/terms link. The local operations dashboard displays collection and failure timestamps and details. All run times are UTC.

| Provider | Scope and access | Result |
| --- | --- | --- |
| NCSI monthly bulletins | Official national transaction-related aggregates. A low-frequency check of the [economic publications index](https://www.ncsi.gov.om/publications?classification=2&page=1) discovers supported PDFs. Older known editions fill gaps. [Government open data terms](https://ncsi.gov.om/ar/TermsAndConditions). | Six monthly editions and the Statistical Year Book, Table 5-3, downloaded and parsed. Table 5-3 covers all 11 governorates for 2025. Latest bulletin edition in this release is November 2026, with figures through October 2026. |
| Ministry of Housing and Urban Planning | Three files from the [open land buy/sell catalog](https://mohup.gov.om/en/open-data/data/Realestate%20Transaction). The catalog lists November/December 2022 and October 2024. [Open data policy](https://mohup.gov.om/pdf/footerFiles/OpenData.pdf). | Three CSV releases downloaded. First run rejected the headerless 2022 layouts. Parser updated and both succeeded on retry. Malformed lines were omitted. Only aggregate row counts were retained. |
| OpenStreetMap contributors | ODbL [terms and attribution](https://www.openstreetmap.org/copyright). Existing geospatial snapshot covers part of Muscat. Standard [OSM tile policy](https://operations.osmfoundation.org/policies/tiles/) applies to map traffic. | 215 repository-snapshot features ingested. Original extraction date is unavailable. Covers mosques, schools, healthcare, shops and parks. |
| Oman Real | Property listings nationwide. [Terms](https://www.omanreal.com/terms-of-use) require prior written approval for collection and allow approved feeds. | 211 private legacy records from two pages. No current collection or republication right verified. |
| OpenSooq Oman | Property listings nationwide. [Terms](https://om.opensooq.com/en/termOfUse) restrict automated harvesting. | 33 private legacy records. A written, authorized feed is required. |
| Bayut Oman | Property listings nationwide. [Group terms](https://www.bayut.com/terms.html) restrict scraping. Oman-specific redistribution terms require confirmation. | 3 private legacy records. A written, authorized feed is required. |
| Geofabrik GCC, Oman Open Data Portal, NCSI Data Portal | OSM extracts, government datasets and housing tables respectively. | Registered for expansion. Source-specific dataset validation and configuration remain. |
| Ebid, Mzadat, Al Mouj Muscat, Homelist, Savills Oman | Auction notices, developer inventory, agency inventory or reports. | Registered as candidates. Feed authorization, terms, retention and public license remain to be verified. |

The Oman Open Government License requires original-source attribution and excludes personal data. The ministry's public CSV includes fields unrelated to the product, including demographic information. The adapter reads the download transiently, derives counts from date, broad geography and nonempty type metadata, and discards raw input without storing or republishing it. No marketplace content was automatically downloaded in this release.
